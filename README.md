Описание
Одностраничный сайт-портфолио геймера и разработчика игр. Страница содержит информацию обо мне, моих навыках, игровых проектах и форму обратной связи. Дизайн выполнен в тёмно-фиолетовой гамме с неоново-зелёным акцентом, с использованием CSS-переменных и эффекта «игровой карточки».

Структура страницы
Шапка (header) — моё имя и фамилия (h1), заголовок страницы (h2) и моё фото.

Основной контент (main)
Секция «Навыки» — маркированный список (ul) с моими основными навыками.
Секция «Проекты» — нумерованный список (ol) из трёх игровых проектов с эффектом «игровой карточки».
Форма обратной связи — поля «Имя», «Email», «Сообщение» и кнопка отправки.

Боковая панель (aside) — указано, на чём мне больше нравится играть, а также навигация по странице.
Подвал (footer) — копирайт с моим именем и годом.

Структура проекта

Особенности CSS
Использованы CSS-переменные для цветов и шрифтов, псевдоклассы :hover, :active, :focus, :visited, а также эффект «поднятия» карточек при наведении и «вдавливания» при нажатии.

Способы подключения CSS
Внешний файл — style.css, подключён через link.
Внутренний блок style — правило для textarea (padding + resize: vertical).
Inline-стиль — на кнопке формы: style="text-transform: uppercase;".

CSS-переменные (:root)
Определены цвета и шрифты. Гамма — тёмно-фиолетовая с неоново-зелёным акцентом:
основной цвет — #15041e (тёмно-фиолетовый);
акцент — #26ff0a (неоновый зелёный);
панель — #2f3f52;
текст — #ecf0f1.

Позиционирование
static — шапка (по умолчанию);
relative — header, footer;
absolute — декоративная иконка footer::after;
fixed — боковая панель aside.

Псевдоклассы
:hover — ссылки, кнопка, карточки проектов;
:active — кнопка, карточки;
:focus — поля ввода формы;
:visited — ссылки в боковой панели.

Эффект «игровой карточки» (вариант 5)
При наведении карточка проекта «поднимается»:
.card:hover { transform: translateY(-5px); box-shadow: 0 8px 20px rgba(38, 255, 10, 0.4); }

При нажатии карточка слегка «вдавливается»:
.card:active { transform: translateY(2px); }

Кнопка формы
При нажатии кнопка смещается вниз:
button:active { transform: translateY(3px); }
